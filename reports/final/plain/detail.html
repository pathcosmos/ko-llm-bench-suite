2. 어떻게 쟀나요

  • 객관식: AI가 보기마다 얼마나 그럴듯하다고 보는지(확률)를 비교해 가장 높은 보기를 답으로 봅니다. 글자 파싱 실수나 위치 편향이 끼지 않습니다.

  • 생성(직접 쓰게 하기): 수학, 지시 따르기, 의료 문제는 정답 규칙으로 채점합니다. 대화와 글쓰기 품질은 큰 AI(Qwen3.6-35B-A3B)가 채점자(judge)로 점수를 매겼습니다.
  • 코드: 만들어진 코드를 격리된 곳에서 실제로 실행해 테스트를 통과하는지 봅니다.
  • 다턴 시나리오: 3~5번 주고받는 대화 300개(수학 조건 변경, 일정 기억, 지시 유지, 모름 인정 등 10범주)를 규칙으로 채점합니다.
  • 속도: 서버를 띄워 질문을 보내며 첫 글자까지 걸린 시간, 초당 생성량, 메모리를 재었습니다.

설정은 미리 정한 규칙으로만 골랐습니다. 별도의 연습용(dev) 문제에서 설정을 고르고 시험(test) 결과를 보고 바꾸지 않았습니다. 규칙은 측정 전에 파일로 등록했습니다.

6. 영역별 해설

객관식 지식

KMMLU, HAE-RAE, Belebele 등 지식 문제는 우리 모델 3종 모두 무작위로 찍는 수준 근처입니다. 신호가 있는 곳은 KoBEST(JANSORI 58.7)와 영어 HellaSwag·ARC(JANSORI 52.6, 38.0. 나머지 둘은 약 30, 23)뿐입니다.

KMMLU 20.4가 무작위(25)보다 낮은 이유

정답은 A 9.9%, B 29.7%, C 29.9%, D 30.5%로 A가 드뭅니다. 그런데 JANSORI는 A 50.5%, B 40.8%로 글자에 쏠려 답했습니다. 정답 분포와 상관없이 이렇게 답하면 기대 정확도가 19.7%이고 관측값과 같습니다. 지식 신호가 없고 글자 편향만 있다는 뜻입니다.

글 이어쓰기

한국어 bits-per-byte는 JANSORI 0.752, frankenstallm 0.795, EVAFRILL 0.82입니다(낮을수록 좋음). 공개 최상위 kanana-2-30b-a3b-base는 0.662입니다. 통일 비교의 환산 점수는 JANSORI 88점입니다.

직접 쓰게 하는 과제

지시 따르기(IFEval-Ko)는 frankenstallm 18.1%, EVAFRILL 14.6%로 공개 소형 모델 35~71%에 못 미칩니다. 의료 문제는 14.7%와 9.6%, 수학(HRM8K)은 거의 0%(요구된 \boxed 답 형식을 99% 지키지 못함), 코드는 0%입니다.

대화·글쓰기(judge)

KoMT 점수는 두 모델 모두 1.1점(10점 만점)이고 공개 모델은 2.4~8.0점입니다. 기준 모델(llama-3.2-3b-instruct)과 맞붙은 승률은 0.16과 0.11입니다(0.5가 동률).

여러 번 주고받는 대화

300개 시나리오를 끝까지 통과한 비율은 우리 모델 0%입니다(턴 통과 0.10, 0.09). 공개 소형 모델은 턴 0.53~0.84, 시나리오 0.30~0.63입니다. frankenstallm은 이전 답을 그대로 복사하는 비율이 16~22%입니다.

9. 읽을 때 주의

  • JANSORI는 base라 대화 평가가 원래 목표 밖입니다. 비교는 가능하지만 해석에 이 점을 반영해야 합니다.
  • 코드는 base 이어쓰기 형식으로 통일해 형식을 못 맞춘 모델의 MBPP+가 0에 가깝습니다(ERNIE-4.5 instruct는 코드 대신 설명문, nemotron-3.5는 378개 중 230개가 문법 오류). 형식 규칙은 측정 전에 정해 바꾸지 않았습니다.
  • 공개 벤치마크 문제가 모델 학습에 섞였을 가능성(오염)은 통제하지 못했습니다.
  • 점수가 낮은 원인(학습 데이터 양, 모델 크기, 학습 방법 등)은 이번 평가로 구분할 수 없습니다.
  • Qwen3.5-4B의 사고(thinking) 모드는 처음 greedy로 실행되어 생각이 잘리는 일이 많았고, 공식 권장 샘플링으로 다시 쟀더니 수학 75.0%에서 79.9%, 지시 수행 31.9%에서 79.2%로 올랐습니다. 반대로 LogicKor와 K2 생성은 내려갔습니다.
